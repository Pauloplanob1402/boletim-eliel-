# Boletim 07 — Protótipo

Protótipo estático (sem build, sem dependências) pra avaliação do piloto do boletim.

## Páginas
- `index.html` — home: demo interativa, o visitante monta o próprio perfil e gera o boletim dele na hora
- `personalizado.html` — demo: digite um nome e veja o boletim se personalizar na hora (assunto, saudação, CTA)
- `edicao.html` — exemplo de uma edição real do boletim, como o assinante recebe
- `pitch.html` — página de apresentação do piloto (pitch)
- `perfil.html` — cópia da home, mantida caso queira linkar separadamente
- `decisao.html` — memorando interno pro Eliel decidir com urgência (escassez, prova social, aversão à perda, StoryBrand)
- `vendas.html` — página de vendas pro assinante final, estilo slippery-slide (Sugarman)

## Páginas — versão Pavinatto
- `pavinatto-perfil.html` — construtor de perfil adaptado (Justiça, Política, Congresso, Segurança), marca "SEM MIMIMI"
- `pavinatto-decisao.html` — página de decisão adaptada pra ele, com o dado real de seguidores dele

## Deploy
Site 100% estático. Não precisa de build command nem install command no Vercel — pode deixar os campos em branco ou usar "Other" como framework preset.
