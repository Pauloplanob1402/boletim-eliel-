# SEM MIMIMI — o briefing do Pavinatto

Protótipo estático (sem build, sem dependências) pra avaliação do piloto do briefing.

## Páginas
- `index.html` — home: demo interativa, o visitante monta o próprio perfil (Justiça, Política, Congresso, Segurança) e gera o briefing dele na hora
- `personalizado.html` — demo: digite um nome e veja o briefing se personalizar na hora (assunto, saudação, CTA)
- `edicao.html` — exemplo de uma edição real do briefing, como o assinante recebe
- `pitch.html` — página de apresentação do piloto (pitch), com quiz e planos
- `perfil.html` — cópia da home, mantida caso queira linkar separadamente
- `decisao.html` — página de decisão pro Pavinatto, com dado real dele (2,2 mi de seguidores no Instagram) e o loop de hábito (Hooked)
- `vendas.html` — página de vendas pro assinante final, estilo slippery-slide (Sugarman)

## Deploy
Site 100% estático. Não precisa de build command nem install command no Vercel — pode deixar os campos em branco ou usar "Other" como framework preset.
